# Лабораторная работа № 2. Коллекции и компараторы в Java

Луцык Андрей Сергеевич

## Описание

В работе рассмотрены коллекции Java, методы класса `Collections`,
итераторы, интерфейсы `Comparable` и `Comparator`, множества,
подсчёт частоты слов с помощью `HashMap` и преобразование `Map`
с обменом ключей и значений.

## Запуск

Исходный код расположен в каталоге `src`.
Классы запускаются отдельно.
