# Java Labs

Учебный проект с примерами работы:

- целочисленных типов;
- переполнения;
- вещественной арифметики;
- побитовых операций;
- строк;
- одномерных массивов;
- двумерных массивов;
- сортировки;
- транспонирования и умножения матриц.

## Требования

- JDK 8 или новее;
- Bash для запуска `build.sh`.
